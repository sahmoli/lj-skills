# Teaching visuals and media

Use this reference when creating or substantially revising a teaching deck.
Choose images, figures, diagrams, and video because they let students see the
current comparison, mechanism, place, or evidence. Put essential prompts,
actions, and error-handling in the upper classroom-visible area and locate labels
at what they name. Preserve the identity of observed evidence. Describe crops,
composites, annotations, and generated conceptual illustrations as derivatives
when the transformation affects interpretation; this does not require watermarking
every crop.

Prepare usable local assets rather than leaving generic "teacher prepares"
placeholders. Reuse authorized course assets where suitable; otherwise research
or create appropriate visual material within the request's authorization and
the available tools. Do not treat this guidance as permission to upload private
teaching content, access external services, or generate replacements for
evidence.

When an approved course deck is the reference, take its actual recurring roles
(title, body, prompt, footer, and any language-specific font handling) from the
file rather than approximating a named theme. Carry the reference version into
the production record. Keep important source identity close to the visual: say
whether it is original evidence, a cited reproduction, a display derivative, or
an illustrative schematic. A reproducible plot calculated from identified data
or formulae is a derived analysis, not fabricated observation; a generated
qualitative schematic must not impersonate either. Retain the source locator,
panel or data identity, and transformations that matter to interpretation. A difficult full figure may
need a labelled crop, enlargement, or a separate comparison before students can
perform the intended reading; do not relabel different panels, places, times, or
variables as one observation.

Walk the final learner view for each important visual or activity: a student
should be able to trace the named object, read the needed values or relation,
and carry out the stated comparison, prediction, or decision. Correct wording
in a title or note does not substitute for the visible evidence, connection, or
feedback it claims.

When video is used, give it a separate cover/task page by default. Put one
observation task and, where useful, duration on the student-facing canvas; keep
technical file paths and return handling in teacher notes. Keep the media as a
separate local file by default and include an offline still. A video is optional,
as are images; quiet, textual, or tabular pages are appropriate when they make
the intended cognitive move clearer.

Use a static PPTX/PDF as the classroom default. Add an interactive component
only when it materially improves the learning task and provide a practical
static fallback.

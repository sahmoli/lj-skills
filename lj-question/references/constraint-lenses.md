# Constraint lenses

Use only the lenses that could change the solution space.

| Lens | Diagnostic question | Common false wall |
|---|---|---|
| Physical / biological | What cannot occur without system failure or biological harm? | Treating a historical range as a physical law |
| Ethical / legal | What must not be done, or carries a real legal/ethical penalty? | Treating institutional convenience as ethics |
| Measurement | What construct cannot currently be observed at the needed resolution? | Treating an available proxy as the construct |
| Identification | Which causal alternatives remain observationally equivalent? | Treating more samples as a cure for missing contrasts |
| Scale | Which spatial, temporal, organismal, or decision unit bounds inference? | Treating native resolution as infinitely refinable |
| Resource | Which time, money, compute, access, or expertise limit changes feasible designs? | Treating a negotiable allocation as immutable |
| Incentive / information | Who bears downside, receives upside, or cannot observe the state? | Explaining strategic behavior as irrationality |
| Convention / self-story | Which rule survives only because nobody has tested a replacement? | Calling precedent a hard requirement |

For ecological work, screen permit/CARE constraints, sensitive-location exposure, animal welfare,
sampling-unit mismatch, detectability, temporal support, and remote-sensing resolution when each could
change the solution space or claim ceiling.

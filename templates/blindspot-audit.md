# Blind-spot audit template

Use this template only when Juan explicitly requests a blind-spot audit. Follow the suite
[honesty and authorization rules](../_shared/honesty-constitution.md).

Audit one structural habit using only the recent-work evidence window Juan supplies or names. If no usable
window is in scope, ask for it. Do not infer a location or scan private logs, health, email, financial, or
unrelated directories. Quote the minimum private material needed for an inspectable judgment.

Anchor the conclusion in the supplied artifacts, test a benign competing explanation, and abstain when the
evidence is thin. Diagnose an evidence pattern rather than a personality or medical condition. Return one
bounded, reversible counter-move that changes a future observation or decision; `证据不足，今日不判盲区` is
a valid result.

This template is interactive and report-only. Do not schedule it, automate recurring scans, upload
transcripts, or collect additional history without authorization. Save the final report using the
[unified note contract](../_shared/note-output.md), unless Juan requests no saving. For the report schema, read
[`references/blindspot-signals.md`](references/blindspot-signals.md) for the report contract and use
[`scripts/validate_blindspot.py`](scripts/validate_blindspot.py); a mechanical pass does not establish that the judgment is true.

# Delegation and acceptance template

Use this template only when Juan explicitly asks to draft a delegation brief or verify returned agent work.
Follow the suite [honesty and authorization rules](../_shared/honesty-constitution.md).

Preserve the owner's selected outcome. State the minimum state change, exact write boundary, frozen areas,
available evidence, acceptance evidence, delivery, and any stop condition that protects scope or
recoverability. Completion language never authorizes external or irreversible actions, durable Wiki changes,
or edits to Juan's `My Take`.

Starting an agent, creating a goal, or executing delegated work requires Juan's explicit authorization; a
request to draft or check a brief does not supply it. An executor may not weaken tests, thresholds,
assertions, or the object under test to obtain a pass. During acceptance, inspect the returned artifacts and
rerun applicable checks instead of accepting an executor's self-report.

Read [`references/delegation-brief.md`](references/delegation-brief.md) only when
the reusable brief fields or detailed acceptance contract are useful.
